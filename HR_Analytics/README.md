# 👥 HR Analytics Dashboard

## 📌 Project Overview

The **HR Analytics Dashboard** is an end-to-end data analytics project that analyzes employee data to identify key factors influencing employee attrition, workforce demographics, job satisfaction, and overall organizational performance.

The project combines **Python** for data preprocessing and **Power BI** for interactive dashboard development, enabling HR professionals to make data-driven decisions.

---

## 🎯 Objectives

* Analyze employee attrition patterns.
* Understand workforce demographics.
* Identify departments and job roles with high attrition.
* Monitor employee satisfaction and performance.
* Build an interactive dashboard for HR decision-making.
