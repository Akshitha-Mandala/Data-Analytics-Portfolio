# ₿ Cryptocurrency Portfolio Analysis

## 📌 Project Overview

The **Cryptocurrency Portfolio Analysis** project provides an interactive dashboard for analyzing cryptocurrency investments and portfolio performance.

Using **Python** for data preprocessing and **Power BI** for visualization, the dashboard helps users monitor price trends, portfolio value, market performance, and investment insights.

---

## 🎯 Objectives

* Analyze cryptocurrency price movements.
* Track portfolio performance.
* Compare different cryptocurrencies.
* Visualize historical trends.
* Generate investment insights.
